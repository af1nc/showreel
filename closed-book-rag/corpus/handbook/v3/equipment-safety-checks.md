# Equipment Safety Checks (Handbook v3)

Every powered machine on the shop floor carries a check card at the operator
station. The check card is the record that the machine was safe to start.

## Checks before you start your shift

Before a machine is energised at the start of a shift, the operator completes the
seven point start check on the check card: every guard interlock closed, the
emergency stop button free and unpainted, the light curtain clear and unobstructed,
hydraulic pressure inside the green band on the gauge, coolant above the minimum
mark, the swarf tray emptied, and the previous shift signature present on the card.

A machine with any one of the seven points failing stays isolated. The operator
raises a fault tag, hangs it at the operator station, and tells the shift lead. An
operator never starts a machine to see whether the fault is still there.

## Weekly checks

The cell supervisor carries out the weekly deep check on every machine in the cell:
an interlock defeat test on each guard, a run down time measurement against the
value on the machine plate, and a visual inspection of every flexible hose for
chafing where it passes over an edge. A machine whose run down time is more than 15
percent longer than the plate value is taken out of service immediately, because a
lengthening run down time means the brake is going.

## Emergency stops

Every emergency stop on a machine is tested as part of the weekly deep check, and
each one is tested individually rather than assuming that testing one proves the
circuit. An emergency stop that has been used in anger is tested again before the
machine goes back into production.

## The check card

Check cards are collected weekly and retained for 24 months. A machine with no
check card completed for more than two consecutive shifts is treated as
uncontrolled: it cannot be run until the cell supervisor has re-baselined it with a
full seven point check and a signature. Backdating a check card is treated as a
falsified record and is a disciplinary matter, because the whole point of the card
is that somebody actually looked.
